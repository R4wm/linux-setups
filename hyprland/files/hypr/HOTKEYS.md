# Hyprland Hotkeys Reference

**SUPER** = Windows key

## Window Management

### Window Splitting & Layout
| Hotkey | Action |
|--------|--------|
| `SUPER + Space` | Toggle split orientation |
| `SUPER + P` | Toggle pseudo-tiling |

### Moving Windows
| Hotkey | Action |
|--------|--------|
| `SUPER + Shift + I` | Move window up |
| `SUPER + Shift + K` | Move window down |
| `SUPER + Shift + J` | Move window left |
| `SUPER + Shift + L` | Move window right |

### Focusing Windows
| Hotkey | Action |
|--------|--------|
| `SUPER + I` | Focus window above |
| `SUPER + K` | Focus window below |
| `SUPER + J` | Focus window left |
| `SUPER + L` | Focus window right |

### Window Actions
| Hotkey | Action |
|--------|--------|
| `SUPER + Shift + C` | Close window |
| `SUPER + F` | Fullscreen |
| `SUPER + V` | Toggle floating |

## Common Programs

| Hotkey | Action |
|--------|--------|
| `SUPER + Return` | Open terminal |
| `SUPER + R` | Open app launcher (wofi) |
| `SUPER + E` | Open file manager |
| `SUPER + X` | Open clipboard manager (rofi) |
| `SUPER + M` | Exit Hyprland |

## Workspaces

### Switch Workspace
| Hotkey | Action |
|--------|--------|
| `SUPER + 1-9` | Switch to workspace 1-9 |
| `SUPER + 0` | Switch to workspace 10 |
| `SUPER + Left/Right Arrow` | Previous/Next workspace |
| `SUPER + Mouse Scroll` | Cycle through workspaces |

### Move Window to Workspace
| Hotkey | Action |
|--------|--------|
| `SUPER + Shift + 1-9` | Move window to workspace 1-9 |
| `SUPER + Shift + 0` | Move window to workspace 10 |

### Scratchpad
| Hotkey | Action |
|--------|--------|
| `SUPER + S` | Toggle scratchpad |
| `SUPER + Shift + S` | Move window to scratchpad |

## Mouse Actions

| Hotkey | Action |
|--------|--------|
| `SUPER + Left Click` | Move window |
| `SUPER + Right Click` | Resize window |

## Media Keys

| Hotkey | Action |
|--------|--------|
| `Volume Up/Down` | Adjust volume |
| `Mute` | Toggle mute |
| `Brightness Up/Down` | Adjust screen brightness |
| `Play/Pause` | Media control |
| `Next/Previous` | Skip tracks |
